Sistema de Gestão de Instituto Superior (SGI)

Protótipo moderno de um Sistema de Gestão para Institutos Superiores, desenvolvido para demonstrar uma solução digital integrada capaz de apoiar a administração académica, financeira e institucional de estabelecimentos de ensino superior.

---

Objetivo

Este projeto apresenta um protótipo funcional de interface (Front-End) de um Sistema de Gestão de Instituto Superior, com o objetivo de ilustrar como diferentes áreas administrativas e académicas podem ser integradas em uma única plataforma digital.

A solução visa apoiar a modernização e digitalização dos processos institucionais.

---

Principais Módulos do Sistema

O sistema foi concebido com base nas necessidades típicas de instituições de ensino superior.

1. Gestão Académica

- Matrículas
- Inscrição por disciplinas
- Gestão de turmas
- Lançamento de notas
- Histórico académico

2. Portal do Estudante

- Consulta de notas
- Situação financeira
- Requerimentos online
- Acesso a materiais didáticos

3. Gestão Financeira

- Propinas e mensalidades
- Emissão de faturas e recibos
- Controlo de pagamentos
- Gestão de dívidas

4. Gestão de Docentes

- Cadastro de professores
- Distribuição de carga horária
- Avaliação de desempenho

5. Recursos Humanos

- Gestão de funcionários
- Processamento salarial
- Férias e faltas

6. Biblioteca

- Cadastro de livros
- Empréstimos e devoluções
- Biblioteca digital

7. Comunicação Institucional

- Avisos institucionais
- Comunicação com estudantes e docentes
- Gestão de eventos académicos

8. Segurança e Controle de Acesso

- Perfis de utilizadores
- Logs de atividades
- Controlo de permissões

9. Relatórios e Business Intelligence

- Estatísticas institucionais
- Indicadores académicos
- Relatórios estratégicos

---

Características do Protótipo

- Interface moderna e responsiva
- Dashboard institucional
- Navegação modular
- Estrutura preparada para expansão
- Possibilidade de integração futura com backend e bases de dados

---

Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript

---

Finalidade do Projeto

Este repositório apresenta um protótipo demonstrativo, desenvolvido para ilustrar como um Sistema de Gestão Institucional pode apoiar a administração e a tomada de decisão em Institutos Superiores.

Estado do Projeto
